# VoidRecorder (Forge 1.16.5, 36.2.42)

Запись реальных кадров игры (мир + HUD + инвентарь + меню) в MP4 (H.264). Только видео, без звука.

## Что реализовано
- Захват кадра из main render target в конце каждого кадра (glReadPixels) в основном потоке — только чтение.
- Масштабирование, H.264-кодирование (JCodec, чистая Java) и запись MP4 — в отдельном потоке.
- Очередь на 3 кадра: если кодер не успевает, кадры пропускаются, игра не блокируется.
- F8 (меняется в Управлении) — старт/стоп; работает и в игре, и в открытых экранах.
- Кнопки REC/STOP, FPS и Width в меню паузы (Esc).
- Настройки: config/voidrecorder-client.toml (fps, outputWidth, showHudIndicator). Высота считается по пропорциям окна при старте записи.
- Файлы: <папка игры>/voidrecordings/rec_ДАТА.mp4

## НЕ реализовано
- Звук. Захват игрового звука не сделан (OpenAL-вывод Minecraft не перехватывается штатно, на Android/MJLauncher надёжного способа нет).
- Аппаратное кодирование (MediaCodec недоступен из JVM-мода).
- Восстановление файла после краша: MP4 финализируется при STOP/выходе из игры.

## Не проверено
Проект не компилировался и не запускался в среде автора. Возможны правки имён маппингов
(official 1.16.5) и API JCodec 0.2.5 при первой сборке; логи сборки покажут конкретные места.
Работа glReadPixels/FBO на GL4ES/ANGLE в MJLauncher и скорость pure-Java кодера на телефоне нужно проверить на устройстве;
начните с 10 FPS и Width 426.

## Сборка через GitHub Actions
1. Создайте репозиторий, залейте содержимое папки (включая .github/workflows/build.yml).
2. Actions → Build VoidRecorder → Run workflow (или просто push).
3. Готовый JAR: Artifacts → VoidRecorder-jar (voidrecorder-1.0.0.jar). Он содержит JCodec внутри.

## Локальная сборка
Java 8 + Gradle 7.4.2: `gradle build` → build/libs/voidrecorder-1.0.0.jar
Установка: положить JAR в папку mods профиля Forge 1.16.5-36.2.42.
